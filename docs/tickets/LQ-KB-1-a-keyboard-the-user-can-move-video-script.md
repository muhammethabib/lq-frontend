# The keyboard the user can move — video script

*Bu script yeni ön yüzde çekiliyor: ekranda görünen davranış, ticket'ta
istenen davranışın ta kendisi. İtalik satırlar senin yapacağın hareketler,
düz satırlar da o sırada okuyacağın metin.*

---

*Arama sayfasını aç, Word Decoder sekmesine geç ve boş harf kutularından
birine bas.*

This is the Word Decoder keyboard. It opens directly under the letter boxes,
and it floats above the page rather than sitting in it.

*Fareyi klavyenin üst çubuğuna getir, birkaç saniye orada tut.*

When the pointer rests on the top bar, a field of small dots appears along it
and the panel lifts a little off the page. The cursor turns into an open hand.
Together these say that the keyboard can be picked up and moved.

*Fareyi tuşların yanındaki boş alana getir.*

The empty space beside the key rows does the same thing. The dots follow the
exact shape of that space, so wherever they appear, the keyboard can be
carried from there.

*Klavyeyi üst çubuğundan tutup sayfanın başka bir yerine sürükle, ama henüz
bırakma.*

While the keyboard is being carried, it follows the pointer exactly — it does
not jump or re-centre itself — and the cursor is a closed hand for as long as
the user holds it.

*Klavyeyi oraya bırak.*

As soon as it is dropped, a small button appears in the top-left corner of the
keyboard and flashes once. That button sends the keyboard back to where it
started.

*Butonun üstünde beliren yazıyı göster, kaybolana kadar bekle.*

The first time in a visit, a short label appears over that button: "Put it
back". It stays for about two seconds and then goes. It is said once only —
moving the keyboard again does not repeat it.

*Fareyi butonun üstüne getir, sayfadaki çerçeveyi göster.*

Hovering the button draws an outline on the page, showing where the keyboard
will go back to.

*Klavyeyi tutup ilk yerinin yakınına doğru sürükle, ama henüz bırakma.*

While the keyboard is being carried back towards its original place, a dashed
outline of that place appears behind it, and it grows clearer as the keyboard
comes closer.

*Klavyeyi çerçevenin üstüne bırak.*

Dropped close enough, the keyboard settles into its original place by itself,
and the button disappears.

*Klavyeyi tekrar başka bir yere taşı, sonra butona bas.*

Pressing the button sends the keyboard back to its original place, and the
button fades away.

*Klavyeyi yine taşı, kapat, sonra bir kutuya basarak tekrar aç.*

A keyboard the user has moved stays where it was put. Closing it and opening
it again brings it back to the same place.

*Sayfayı F5 ile yenile ve bir kutuya bas.*

After the page is reloaded, the keyboard opens in its usual place under the
boxes again. Where the user put it is not remembered between visits.

*Klavyenin sol alt köşesindeki Gelişmiş / Temel tuşunu göster.*

The Advanced and Basic key sits in the bottom-left corner of the panel, flush
with its left edge and its foot.

*Arama sekmesine geç ve oradaki klavyeyi de aç, kısaca taşı.*

The keyboard on the Search tab behaves in exactly the same way.

*Tarayıcı penceresini telefon genişliğine kadar daralt ve klavyeyi aç.*

On phone-size windows the keyboard sits along the bottom of the screen. There
is nowhere to move it to, so none of this applies: no dots, no hand, and no
button in the corner.
